# 时光音盒 · 移动端音乐与实时时钟

基于 HTML5、CSS3、JavaScript 和 Vue 3 实现的移动前端课程设计作品。

## 功能

- 实时显示本地时间、日期、星期和问候语
- 选择手机中的一个或多个 MP3 文件
- 播放、暂停、上一首、下一首、进度拖动、音量调节
- 播放列表、歌曲删除、自动播放下一首
- 深色/浅色主题切换
- 响应式手机布局，适合移动浏览器展示

## 运行方式

直接打开 `index.html` 即可运行；也可以用 VS Code 的 Live Server 启动本地服务。点击“添加音乐”选择本地 MP3 后，再点击播放按钮开始播放。

项目使用 Vue 3 CDN，不需要 `npm install` 或构建步骤。首次打开时需要网络加载 Vue 和字体 CDN；如果课程环境不能联网，可以将 Vue 3 文件下载到本地后，把 `index.html` 中的 CDN 地址替换为本地路径。
